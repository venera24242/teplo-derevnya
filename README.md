# Тёплая деревня / teplo-derevnya.ru

Статический лендинг для проекта базы отдыха.

## Деплой на REG.RU

1. Подключитесь по SSH к хостингу REG.RU.
2. Перейдите в корневую папку сайта (обычно `~/www/teplo-derevnya.ru` или аналогично — проверьте в панели).
3. Выполните:
```bash
git clone https://github.com/venera24242/teplo-derevnya.git .
```
(точка в конце обязательна — чтобы файлы легли прямо в корень)

4. Затем загрузите папку `assets/` из подготовленного архива рядом с `index.html`.

Для обновлений позже: `git pull`

Сайт: https://teplo-derevnya.ru
