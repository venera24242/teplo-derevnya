# Тёплая деревня / teplo-derevnya.ru

Статический лендинг проекта базы отдыха. Форма «Узнать об открытии» сохраняет адрес электронной почты через PHP.

## Деплой на REG.RU

Все файлы сайта, включая папку `assets/`, уже лежат в корне репозитория.

1. Подключитесь по SSH к хостингу REG.RU.
2. Перейдите в корневую папку сайта (обычно `~/www/teplo-derevnya.ru` — проверьте в панели).
3. Если репозиторий ещё не клонирован:

```bash
git clone https://github.com/venera24242/teplo-derevnya.git .
```

(точка в конце обязательна — файлы должны лечь прямо в корень.)

Если репозиторий уже есть, достаточно обновить его:

```bash
git pull
```

Если SSH недоступен, загрузите в корень сайта архив `teplo-derevnya-deploy.zip` через файловый менеджер панели REG.RU.

Сайт: https://teplo-derevnya.ru

## Форма «Узнать об открытии»

Форма на главной отправляет данные на `api/opening.php` (на хостинге REG.RU PHP поддерживается). Сохраняются только email и согласие; телефон и мессенджеры не собираются.

Заявки дописываются в файл `data/opening-requests.csv` (время в UTC, email, согласие, IP). Папка `data/` закрыта от просмотра из интернета файлом `data/.htaccess`. CSV в Git не хранится.

Оператор персональных данных указан в `politika.html`: ИП Шарипова В.С., ИНН 720692358679.

## Локальная проверка

```bash
php -S localhost:8080 router.php
```

`router.php` нужен только встроенному серверу PHP (чтобы закрыть `/data/`). На Apache / REG.RU он не используется.
